# Changelog

## 0.1.0 - 2026-06-01

First public-ready build.

### Added

- Per-app Windows volume control through MIDI notes.
- Master output control.
- MIDI bindings for mute, hold mute, volume up, volume down, set volume, and lower while held.
- Automatic MIDI device reconnect and device selection.
- Import and export of settings.
- Backup before settings import.
- Hidden app list editing.
- Cached app icons for known applications.
- Dark, light, and system theme modes.
- Russian and English interface languages.
- Start with Windows option.
- Tray icon and tray menu.
- Portable self-contained Windows build.

### Fixed

- Stable tray-only startup when launched through Windows autostart.
- Responsive manual volume slider updates.
- Styled application dialogs for the current theme.
